# Python Mark Grading Program

## 📌 About the Project

This project was originally developed as part of an **academic programming assignment** to demonstrate fundamental Python programming concepts.

After completing the assignment, the program was **further improved and enhanced** before being uploaded to GitHub. The updated version includes additional input validation, error handling, and program control features to make the program more robust and user-friendly.

The program accepts a student's mark, validates the input, and displays the appropriate result based on the mark range.


## ✨ Features

* Accepts marks from **0 to 100**
* Displays **Fail**, **Credit**, or **Distinction**
* Validates marks entered by the user
* Handles non-numeric input using **try-except**
* Prevents marks above 100 from being accepted
* Allows the user to exit by entering a negative number
* Continuously accepts marks until the user chooses to exit
* Uses **functions** to organise the grading logic
* Uses **input validation** to handle invalid entries
* Provides clear and user-friendly messages


## 📊 Grading Criteria

| Mark Range | Result      |
| ---------- | ----------- |
| 0–49       | Fail        |
| 50–69      | Credit      |
| 70–100     | Distinction |

## 🛠️ Technologies Used

* **Python 3**
* **PyCharm IDE**

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project using a Python-compatible IDE or editor.
3. Open the `mark_grading.py` file.
4. Run the program using a Python interpreter.
5. Enter a mark between **0 and 100**.
6. The program will display the corresponding result.
7. Enter a **negative number** to exit the program.
